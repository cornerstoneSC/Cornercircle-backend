# Media

## Exceptions

### MediaUploadException.java

```java
public class MediaUploadException extends RuntimeException 
```

- means you are creating your own custom exception called MediaUploadException.
  - Breakdown :
    - `public` → the class can be used from other packages.
    - `class` → you are defining a Java class.
    - `MediaUploadException` → the name of your custom error.
    - `extends RuntimeException` → it inherits Java’s built-in runtime exception behavior.
- So instead of throwing a generic error like:
  - Use this when Cloudinary itself fails.
    For example:
    ```java
    throw new MediaUploadException(
        "Failed to upload image to Cloudinary.",
         exception
    );
    ```

### Constructor with message

```java
public MediaUploadException(String message) {
    super(message);
}
```

- This is a constructor. It’s a special method that runs when someone creates a new MediaUploadException.
  - Breakdown :
    - `public` → the constructor can be used from other packages.
    - `MediaUploadException` → the name of the constructor (it matches the class name).
    - `(String message)` → it takes a single string as input.
    - `super(message)` → it calls the parent class’s constructor (RuntimeException) and passes the message to it.

### Constructor with message and cause

```java
public MediaUploadException(String message, Throwable cause){
```

- This is another constructor. It’s a special method that runs when someone creates a new MediaUploadException.
  - Breakdown :
    - `public` → the constructor can be used from other packages.
    - `MediaUploadException` → the name of the constructor (it matches the class name).
    - `(String message, Throwable cause)` → it takes a string and an exception as input.
    - `super(message, cause)` → it calls the parent class’s constructor (RuntimeException) and passes the message and cause to it.

## DTOs

### ImageUploadResponse.java

```java
public record ImageUploadResponse(String url, String publicId) {
}
```

- This is what your media service returns after a successful Cloudinary upload.
  - Example:
    ```json
    {
      "url": "https://res.cloudinary.com/your-cloud/image/upload/v123/cornerstone/homepage/image.jpg",
      "publicId": "cornerstone/homepage/abc123"
    }
    ```
- This is a record. It’s a special type of class that automatically generates getters, constructors, and other useful methods.
  - Breakdown :
    - `public` → the record can be used from other packages.
    - `record` → you are defining a Java record.
    - `ImageUploadResponse` → the name of the record.
    - `(String url, String publicId)` → it takes a string and an exception as input.
    - → it calls the parent class’s constructor (RuntimeException) and passes the message and cause to it.

### What is a record?

- A record is a special type of class that automatically generates getters, constructors, and other useful methods.

### What is a DTO?

- A DTO (Data Transfer Object) is a simple object that is used to transfer data between different layers of an application. 

### Is the record declaration a constructor?

```java
public record ImageUploadResponse(String url, String publicId)() 
```

- Yes, it is a constructor. It is a compact constructor that takes two parameters: url and publicId.
- It is a special type of constructor that is used to initialize the fields of the record.
- It is automatically generated by the Java compiler.
